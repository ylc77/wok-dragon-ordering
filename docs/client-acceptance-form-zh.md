## 三、现场验收项目

### 1. 前台网站

- [ ] 首页可打开
- [ ] 餐馆名称、地址、电话、营业时间正确
- [ ] 公开菜单可打开
- [ ] 菜品分类、菜名、价格正确
- [ ] 手机端显示正常
- [ ] 英文 / 希腊语切换正常

### 2. 扫码点餐

- [ ] 扫桌台二维码可进入点餐页
- [ ] 可以开始点餐
- [ ] 可以选择菜品
- [ ] 可以选择口味选项
- [ ] 可以加入购物车
- [ ] 可以提交订单
- [ ] 后台能看到新订单
- [ ] 请求结账入口正常
- [ ] 清桌后旧手机不能继续下单

### 3. 后台管理

- [ ] 管理员账号可登录
- [ ] 订单列表显示正常
- [ ] 可以确认收款
- [ ] 可以清桌
- [ ] 可以新增 / 编辑菜品
- [ ] 可以上架 / 下架 / 售罄菜品
- [ ] 可以管理分类
- [ ] 可以管理桌台二维码
- [ ] POS 前台点单可创建订单

### 4. 打印助手

- [ ] Windows 测试页可打印
- [ ] 测试小票可打印
- [ ] 扫码订单可自动打印厨房小票
- [ ] POS 订单可自动打印厨房小票
- [ ] 客户已知晓打印助手窗口不能关闭
- [ ] 客户已知晓电脑关机后不会自动打印

## 四、重要说明确认

请客户确认已知晓：

- [ ] 厨房小票不是希腊税务正式发票。
- [ ] 正式税务收据仍由餐馆原收银机、税控 POS 或合法税务系统开具。
- [ ] 打印助手依赖前台 Windows 电脑和本地打印机。
- [ ] 如果电脑、网络或打印机异常，自动打印可能暂停。
- [ ] 客户需要自行核对菜单价格、营业时间和联系方式。
- [ ] 修改菜单和价格后，建议现场再测试一次下单。
