# Wok Dragon 餐馆扫码点餐系统商业交付版 1.0

本文档用于给客户、合作方或实施人员说明：这个系统适合什么场景、由哪些部分组成、交付边界是什么，以及后续可以如何升级。

## 一、适合什么餐馆

本系统适合以下类型的小型和中型餐饮商家：

- 中餐馆、快餐店、小吃店
- 奶茶店、咖啡店、甜品店
- 堂食为主、同时支持外带的餐馆
- 需要英文 / 希腊语菜单展示，但老板或员工更习惯中文后台的商家
- 希望顾客扫码点餐，同时前台也可以人工 POS 点单的商家

如果餐馆目前已经有正式收银机或税务 POS，本系统可以作为“点餐 + 菜单 + 后台管理 + 厨房小票”的补充工具使用。

## 二、系统组成

商业交付版 1.0 由四部分组成：

### 1. 线上餐馆网站

- 餐馆首页
- 公开菜单 `/menu`
- 英文 / 希腊语前台显示
- 手机端适配
- 地址、电话、营业时间、外卖平台链接等展示

### 2. 顾客扫码点餐

- 顾客扫描桌台二维码进入点餐页
- 支持选择菜品、数量、口味选项和备注
- 支持同桌多人加菜
- 支持提交订单和请求结账
- 清桌后旧顾客不能继续向旧桌台会话下单

### 3. 后台管理系统

- 中文后台
- 订单管理
- 菜单、分类、菜品图片管理
- 桌台和二维码管理
- POS 前台人工点单
- CSV 菜单导入 / 导出
- DeepSeek 自动翻译菜单字段
- 订单收款、清桌和归档管理

### 4. Supabase + 本地打印助手

- Supabase 提供数据库、登录、Storage 图片、RLS 权限和 RPC
- Vercel 部署前台和后台网页
- Windows 本地打印助手负责监听新订单并自动打印厨房小票
- 打印助手使用客户本地 Windows 打印机，不把 service role key 放到客户电脑

## 三、厨房小票和税务发票说明

本系统生成的是：

- 厨房小票
- 点菜单
- 前台订单确认小票

这些小票用于厨房制作、前台核对和内部管理。

重要说明：

- 本系统的小票不是希腊税务正式发票。
- 本系统不替代餐馆原有税务收银机、税控 POS 或 AADE 相关设备。
- 正式税务收据仍应由餐馆现有的合法收银机、POS 或税务系统开具。
- 如需对接正式税务发票或本地支付系统，需要单独评估和定制。

## 四、基础版功能范围

基础版建议包含：

- 餐馆官网首页
- 公开菜单
- 扫码点餐
- 后台订单管理
- 菜单和分类管理
- 桌台二维码管理
- POS 前台人工点单
- 浏览器小票打印
- Windows 本地打印助手自动打印厨房小票
- CSV 菜单导入 / 导出
- 英文 / 希腊语前台、中文后台
- 基础部署和一次现场配置

## 五、专业版后续扩展方向

根据客户预算和实际业务，可以后续升级：

- 多打印机：厨房、吧台、收银分别打印
- 打印助手图形化配置界面
- 手动重打小票和打印队列面板
- 老板经营报表：日销售额、热销菜品、付款方式统计
- 员工权限分级：老板、店员、只看订单
- 会员 / 优惠券 / 积分
- 库存扣减
- 外卖平台或支付系统对接
- 正式热敏打印机 ESC/POS 深度适配
- 多门店管理
- 独立多租户 SaaS 版本

## 六、交付边界

商业交付时建议明确：

- 客户需要提供餐馆信息、菜单、价格、图片、Logo 和营业时间。
- 客户需要准备可联网的 Windows 前台设备。
- 客户需要提前安装好打印机驱动，并能打印 Windows 测试页。
- 如果客户修改菜单、图片、价格或桌台，需要按后台使用说明操作。
- 数据库、部署环境和打印助手配置属于交付检查内容，应留有交付记录。
- 税务发票、刷卡支付、外卖平台自动同步等不属于基础版默认范围。
