# 上线前检查清单

本文档用于正式部署前最后验收。建议每次交付客户前都按顺序执行。

## 一、代码和构建检查

- [ ] `npm run typecheck` 通过
- [ ] `npm run build` 通过
- [ ] `npm test` 通过
- [ ] `npm run smoke` 通过
- [ ] `git status` 没有不该提交的临时文件
- [ ] 没有提交 `.env.local`
- [ ] 没有提交 `print-agent/config.json`
- [ ] 没有提交 `print-agent/logs/`
- [ ] 没有提交真实密钥、后台密码或 service role key

## 二、Supabase 检查

- [ ] 新客户只执行 `supabase/client-init.sql`
- [ ] 没有执行 `supabase/schema.sql`
- [ ] 管理员账号已创建
- [ ] `profiles` 中管理员角色是 `admin` 或 `staff`
- [ ] Storage 图片可公开读取
- [ ] 普通顾客不能上传菜单图片
- [ ] RLS / RPC 没有临时关闭
- [ ] `menu-images` 上传权限符合后台 staff/admin 使用

## 三、Vercel 环境变量检查

必填：

- [ ] `VITE_SUPABASE_URL`
- [ ] `VITE_SUPABASE_PUBLISHABLE_KEY`

可选：

- [ ] `DEEPSEEK_API_KEY`

不要配置：

- [ ] 没有配置 `SUPABASE_SERVICE_ROLE_KEY`
- [ ] 没有把真实密钥写入前端代码

## 四、前台网站检查

- [ ] 首页可以打开
- [ ] 餐馆名称、地址、电话、营业时间正确
- [ ] 首页图片、Logo 正常
- [ ] 外卖链接、地图链接、社交链接正确
- [ ] `/menu` 公开菜单可以打开
- [ ] 菜品图片正常，有 fallback
- [ ] 英文 / 希腊语切换正常
- [ ] 手机端没有明显横向滚动

## 五、扫码点餐检查

使用真实手机测试：

- [ ] 扫桌台二维码能打开点餐页
- [ ] 桌台信息正确
- [ ] 可以开始点餐
- [ ] 可以选择菜品
- [ ] 可以选择口味选项
- [ ] 可以加入购物车
- [ ] 可以提交订单
- [ ] 提交后后台能看到订单
- [ ] 请求结账入口正常
- [ ] 清桌后旧手机不能继续向旧 session 下单
- [ ] 新顾客重新扫码可以进入新流程

## 六、后台检查

- [ ] `/admin` 可以登录
- [ ] 仪表盘显示正常
- [ ] 订单列表显示正常
- [ ] 订单状态可以更新
- [ ] 确认收款正常
- [ ] 清桌入口正常
- [ ] 菜品新增 / 编辑 / 隐藏正常
- [ ] 分类新增 / 编辑 / 归档正常
- [ ] 桌台新增 / 删除 / 二维码下载正常
- [ ] 菜单 CSV 导入 / 导出正常
- [ ] DeepSeek 自动翻译正常，或已确认客户不使用
- [ ] 图片上传正常
- [ ] POS 前台点单可以创建订单
- [ ] POS 浏览器小票预览正常

## 七、本地打印助手检查

- [ ] Windows 打印机驱动已安装
- [ ] Windows 测试页可打印
- [ ] `pnpm print-agent -- --setup` 已完成
- [ ] `print-agent/config.json` 已生成在客户本地
- [ ] `pnpm print-agent -- --test-print` 可打印样例小票
- [ ] 新扫码订单可以自动打印厨房小票
- [ ] 新 POS 订单可以自动打印厨房小票
- [ ] 打印成功后不会重复出纸
- [ ] 打印助手窗口关闭后已向客户说明不会继续自动打印
- [ ] 如需开机自启，`pnpm print-agent -- --install-startup` 已设置

## 八、客户交付确认

- [ ] 客户知道如何登录后台
- [ ] 客户知道如何修改菜单和价格
- [ ] 客户知道如何下载桌台二维码
- [ ] 客户知道厨房小票不是税务正式发票
- [ ] 客户知道正式税务收据仍由原收银机 / POS 开具
- [ ] 客户知道打印助手窗口不能关闭
- [ ] 客户知道遇到打印失败先检查纸张、网络和打印机
- [ ] 客户已保存维护联系方式
