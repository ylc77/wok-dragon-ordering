# 餐馆后台使用指南

本指南面向餐馆老板和员工，用最简单的中文说明如何操作后台。

## 如何登录

1. 打开浏览器，访问你的餐馆后台地址（例如 `https://你的域名.com/admin`）
2. 输入邮箱和密码，点击登录
3. 如果看到"该账户没有后台管理权限"，联系技术人员

## 仪表盘

登录后看到的第一个页面就是仪表盘，显示：

- **今日订单** — 今天一共收到了多少单
- **今日营业额** — 今天已付款的总金额
- **待处理订单** — 还有多少单没处理
- **使用中桌台** — 现在有几桌在用餐
- **热销菜品** — 今天卖得最好的菜品
- **最近30天统计** — 过去一个月每天的数据

点击右上角「刷新」可以更新数据。

## 查看新订单

1. 点击左侧「订单」
2. 新订单会出现在列表里，有声音提醒
3. 每个订单显示：桌号、订单号、下单时间、菜品列表、总价
4. 黄色卡片是顾客请求结账

## 确认收款

1. 在订单页面看到黄色「请求结账」提示
2. 点击「确认收款并清桌」
3. 弹出确认框，点击确认
4. 订单变为已付款，该桌自动清空

> ⚠️ 确认收款后不能撤销，请确认顾客已付款再点。

## 清桌

顾客离开后需要清桌：

1. 点击「桌台」
2. 找到对应桌号
3. 如果该桌没有未完成订单，点击「清桌」
4. 清桌后旧页面不能再下单

## 暂停 / 恢复接单

遇到特殊情况需要暂停接单：

1. 点击「餐馆」
2. 看到绿色「全店正在接单」
3. 点击「暂停接单」
4. 顾客端会显示暂停提示，不能提交新订单
5. 处理完后点击「恢复接单」

## 管理菜单分类

1. 点击「分类」
2. 可以创建、编辑、删除分类
3. 例如：前菜、主菜、饮品等
4. 排序数字越小的分类排在前面
5. 禁用的分类不会在前台显示

## 管理菜品

1. 点击「菜品」
2. 可以搜索、筛选菜品
3. 点击「编辑」修改菜品信息
4. 点击「复制」快速创建相似菜品
5. 点击「删除」永久删除菜品（需要输入删除密码）

### 新增菜品

1. 点击顶部「新增」
2. 填写菜品信息（中文、英文、希腊语）
3. 选择分类
4. 输入价格
5. 上传菜品图片（点「上传图片」按钮）
6. 选择状态（上架 / 下架 / 售罄）
7. 点击「保存」

### 菜品状态说明

- **上架**：前台正常显示，顾客可以点
- **下架**：前台不显示
- **售罄**：前台显示但标注"售罄"，顾客不能点

### 批量操作

选中多个菜品后，可以：
- 批量改价
- 标记售罄
- 批量下架
- 批量删除（需要密码）

## 上传菜品图片

1. 编辑菜品时，点击「上传图片」
2. 选择手机相册里的照片
3. 系统自动压缩，上传成功后会显示预览
4. 保存菜品后图片不会丢失

## 桌台和二维码

1. 点击「桌台」
2. 可以新增、编辑桌台
3. 每张桌台有一个固定二维码
4. 点击「下载二维码」保存二维码图片
5. 打印张贴到对应桌面

## 修改餐馆信息

1. 点击「餐馆」
2. 可以修改：
   - 餐馆名称（中文、英文、希腊语）
   - 地址
   - 营业时间
   - 餐馆介绍
   - Logo 和首页大图
   - 电话、WhatsApp、Instagram
   - Google Maps 链接
   - Wolt、efood、Box 外卖链接
   - 现金/刷卡付款方式
3. 填写后点击底部「保存」

> 不想显示的外卖链接留空即可。

## 顾客扫码点餐流程

1. 顾客用手机扫描桌上的二维码
2. 进入点餐页面，选择菜品
3. 加入购物车，可以加减数量
4. 点击底部购物车 → 提交订单
5. 点「请求结账」→ 选择现金或刷卡
6. 后台收到结账请求，确认收款
7. 清桌后顾客不能继续点餐
8. 新顾客重新扫码开始新的用餐

## 常见问题

### 顾客不能下单怎么办？

检查：
1. 「餐馆」页面是否暂停了接单
2. 「餐馆」页面付款方式是否都关闭了
3. 菜品是否都是下架或售罄状态

### 菜品图片不显示？

1. 检查「菜品」编辑区图片URL是否为空
2. 重新上传一次图片
3. 确认保存了

### 订单没有出现？

1. 点击右上角刷新
2. 检查日期筛选是否选择了正确日期
3. 确认顾客是否真的提交了订单

### 清桌后顾客怎么重新点餐？

清桌后，下一批顾客扫描桌上的同一个二维码，会自动创建新的点餐。
旧顾客的页面会显示"点餐已结束"，让他们重新扫码。

### 如何临时暂停接单？

「餐馆」→ 点击「暂停接单」。
处理完后点「恢复接单」。
