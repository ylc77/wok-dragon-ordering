# 在线预订模块交付清单

这是一份模板交付检查清单。项目当前不包含任何真实餐馆或顾客数据，也不会自动发送外部通知。

## 新客户启用步骤

1. 为客户创建独立 Supabase 项目，并执行 `supabase/client-init.sql`。
2. 在供应商入口 `/settings` 选择专业版，或单独开启“在线预订”。
3. 在客户 Supabase SQL Editor 执行 `supabase/reservations-module.sql`。
4. 进入客户后台“预订管理”，设置营业时段、每时段容量、提前预约天数和当天最少提前时间。
5. 在手机端打开 `/reservations`，创建一条测试预约。
6. 确认后台能看到预约，并能完成、取消、标记未到店。

## 通知说明

第一版不发送邮件、WhatsApp、Telegram 或其他外部通知。新预订会直接进入后台“预订管理”，由餐馆员工查看和处理。

## 上线验收

- [ ] 顾客可选择日期、时间和人数。
- [ ] 满额时段不能继续确认。
- [ ] 新预约会显示在后台。
- [ ] 顾客电话和备注只对 staff/admin 可见。
- [ ] 取消预约后，该时段容量会释放。
- [ ] 新预订会出现在后台列表，不会自动发送外部通知。
- [ ] 基础版或未启用预约模块时，前台不显示预订入口。

## 重要说明

在线预订默认自动确认，但不收订金，也不替代餐馆的正式收银、税务或会计流程。顾客取消或修改预约时，请通过餐馆电话或 WhatsApp 处理。
