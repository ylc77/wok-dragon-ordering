# 本地打印助手客户使用指南

这份说明给餐馆老板或店员看，不需要懂技术。

## 一、这个程序是做什么的

本地打印助手安装在前台 Windows 电脑上。

它会自动查看有没有新订单。如果有新订单，就把厨房小票发送到店里的打印机。

它适合打印：

- 顾客扫码点餐订单
- 前台 POS 人工点单订单
- 厨房制作小票

注意：这个小票不是税务发票。正式税务收据仍然用店里原来的收银机或 POS 开。

## 二、每天怎么启动

如果已经设置了开机自启：

1. 打开前台电脑。
2. 等系统启动完成。
3. 看到打印助手窗口后，不要关闭。

如果没有设置开机自启：

1. 打开项目文件夹。
2. 双击：

```text
print-agent\start-print-agent.cmd
```

或者让安装人员在终端运行：

```powershell
pnpm print-agent
```

## 三、重要提醒

- 打印助手窗口必须保持打开。
- 关闭窗口后，不会继续自动打印。
- 电脑关机后，不会继续自动打印。
- 电脑睡眠后，可能会影响自动打印。
- 网络断开时，可能暂时收不到新订单。

## 四、如何测试打印

双击：

```text
print-agent\test-print.cmd
```

或运行：

```powershell
pnpm print-agent -- --test-print
```

如果打印机正常，会打印一张测试厨房小票。

## 五、如何查看打印机列表

双击：

```text
print-agent\list-printers.cmd
```

或运行：

```powershell
pnpm print-agent -- --list-printers
```

如果店里有多台打印机，可以把正确的打印机名称填到配置里。

## 六、如何修改配置

通常不需要自己改。

如果换了打印机、换了 Supabase 项目或换了后台账号，可以让安装人员重新运行：

```powershell
pnpm print-agent -- --setup
```

配置会保存到：

```text
print-agent\config.json
```

这个文件只放在本地电脑里。

## 七、打印失败怎么办

打印失败时，系统不会把订单标记成已打印。下一轮检查时会继续尝试打印，避免丢单。

可以先检查：

1. 打印机是否开机。
2. 打印机是否有纸。
3. 打印机是否卡纸。
4. Windows 测试页是否能打印。
5. 打印助手窗口是否还开着。
6. 网络是否正常。

## 八、日志在哪里

如果需要排查问题，可以把这个文件发给安装人员：

```text
print-agent\logs\print-agent.log
```

日志里会记录打印助手启动、发现订单、打印成功或失败的情况。

## 九、什么时候需要联系维护人员

遇到以下情况建议联系维护人员：

- 换了新打印机
- 换了前台电脑
- 打印内容经常乱码
- 订单在后台有，但一直不打印
- 后台账号密码变了
- 网站域名或 Supabase 项目换了
